# Raytracer

Отдельный учебный рейтрейсер на C++20. Реализация выделена из локального репозитория `rodaziskin`; описания задания и примеры сцен — из `public-2026-summer`. Содержит интерфейсы геометрии, материалов, сцены, камеры и рендеринга, вспомогательный класс PNG-изображения и примеры OBJ/MTL-сцен.

Реализованы геометрия, чтение OBJ/MTL, режимы глубины и нормалей, освещение, отражения и преломление. Добавлена программа `render_scene` для запуска с камерой, настроенной на Cornell Box. Изображения в документации относятся к исходному заданию.

## Структура

```text
src/              Реализация и программа запуска
include/          Заголовки геометрии, сцены, рендера и PNG
include/options/  Настройки камеры и рендеринга
docs/             Исходные описания учебных заданий
docs/images/      Иллюстрации из задания
examples/scenes/  Примеры сцен OBJ и материалов MTL
CMakeLists.txt    Независимая настройка зависимостей
```

Тесты, служебные скрипты курса и остальные задания не перенесены. Исходный репозиторий сохранён без изменений.

## Зависимости и настройка

Нужны компилятор с поддержкой C++20, CMake 3.16+ и библиотека libpng с заголовками. В Ubuntu/Debian пакет называется `libpng-dev`.

```bash
cmake -S . -B build
cmake --build build
```

Сборка создаёт библиотеку `raytracer` и программу `render_scene`.

```bash
mkdir -p output
./build/render_scene examples/scenes/classic_box/CornellBox.obj output/cornell.png
```

Программа принимает путь к сцене и выходному PNG. Камера: `(-0.5, 1.5, 0.98)`, направление на `(0, 1, 0)`, размер 500×500, глубина 4. Для других сцен параметры камеры можно изменить в `src/main.cpp` либо использовать библиотечную функцию `Render`.

## Ограничения

- BVH не реализован: поиск пересечений перебирает объекты.
- Недоступные OBJ/MTL и неверные индексы сцены вызывают сообщение об ошибке. Объекты без назначенного материала используют белый диффузный материал. Нулевой вектор нельзя нормализовать.
- Запуск и рендер Cornell Box проверены локально; полный набор учебных проверок не переносился.

Исходный `image.h` также требует доработки обработки ошибок: ошибки libpng вызывают `abort()`, а часть ранних ошибок создания структур оставляет открытый файл. Этот вспомогательный код сохранён из задания.

## Git

Файлы `.obj` здесь — модели сцен; они намеренно не исключены через `.gitignore`. Сборки и будущие результаты в `output/` игнорируются.

После просмотра подготовленных файлов:

```bash
git diff --cached --stat
git commit -m "Extract standalone raytracer implementation"
```

Для нового пустого репозитория GitHub скопируйте его SSH-адрес и настройте отправку:

```bash
git remote add origin git@github.com:YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```
